# 项目级编码规范

> 在 `project/` 目录下按**项目名**存放独立的规范文件。
> AI 优先读取 `memory.md`（个人偏好），再根据当前项目路径查找对应的项目规范文件并合并。

---

## 目录结构

```
project/
├── README.md              # 本文件
├── _template.md           # 模板——新建项目时复制
└── <项目名>.md            # 按项目名命名的规范文件
```

## 工作流程

当 AI 每次应用规约前：

```
① 读取 memory.md → 载入个人偏好
② 从工作目录推断当前项目名
③ 查找 project/<项目名>.md
④ 若存在 → 读取并合并到 memory.md 之上
⑤ 若不存在 → 仅用 memory.md
```

**项目名推断规则**：从当前工作目录路径中提取顶层项目目录名（如工作路径为 `D:\projects\物业系统\contract-service`，则项目名为 `物业系统`）。

## 创建新项目规范

1. 复制 `_template.md` 为 `<项目名>.md`
2. 按实际情况填写各表格
3. 提交到版本库，团队成员共享
